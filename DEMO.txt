OPCION 2: TERMINAL LOCAL
--------------------------------------------------------------------------------

Instalar:

  python -m pip install -U legal-expand==1.4.1

Expandir texto desde stdin:

  printf "La AEAT gestiona el IVA segun el BOE.\n" | legal-expand

Expandir un archivo:

  legal-expand sentencia.txt --expand-only-first --output sentencia-expandida.txt

Generar auditoria:

  legal-expand audit sentencia.txt --report-format markdown --output audit.md

Generar glosario:

  legal-expand glossary sentencia.txt --glossary-format csv --output glosario.csv

Procesar una carpeta:

  legal-expand batch docs/ docs-expandidos/ --format html


OPCION 3: PYTHON
--------------------------------------------------------------------------------

Expansion basica:

  from legal_expand import expandir_siglas

  texto = "La AEAT gestiona el IVA segun el BOE."
  print(expandir_siglas(texto))

Salida estructurada:

  from legal_expand import ExpansionOptions, expandir_siglas

  resultado = expandir_siglas(
      "AEAT y BOE",
      ExpansionOptions(format="structured"),
  )
  print(resultado.to_json(indent=2))

Diagnostico de omisiones:

  from legal_expand import ExpansionOptions, expandir_siglas_detallado

  resultado = expandir_siglas_detallado(
      "Visita https://aeat.es y revisa AEAT y BOE",
      ExpansionOptions(include=["AEAT"]),
  )
  for omitida in resultado.omitted_acronyms:
      print(omitida.acronym, omitida.reason)


ASISTENTE BOE
--------------------------------------------------------------------------------

El asistente BOE no interpreta juridicamente el documento. Detecta referencias
explicitas, enlaza normas cuando hay seguridad suficiente y marca lo dudoso como
ambiguous, not-found, unsupported o needs-boe-search.

Modo offline, determinista y sin red:

  legal-expand boe sentencia.txt --output referencias-boe.md

Salida JSON:

  legal-expand boe sentencia.txt --report-format json --output referencias-boe.json

Modo con cache y consulta opcional a BOE:

  legal-expand boe sentencia.txt --mode cache-first --timeout 4 --output referencias-boe.md

Python:

  from legal_expand import detectar_referencias_boe, boe_report_to_markdown

  texto = "El art. 24 de la Constitucion Espanola reconoce la tutela judicial."
  informe = detectar_referencias_boe(texto)
  print(boe_report_to_markdown(informe))


OVERRIDES MANUALES BOE
--------------------------------------------------------------------------------

Si el detector no puede resolver una referencia y la persona revisora si conoce
la norma correcta, se puede anadir un override JSON:

  {
    "references": [
      {
        "text": "la norma especial de informantes",
        "boe_id": "BOE-A-2023-4513",
        "title": "Ley 2/2023, de 20 de febrero",
        "unit": "articulo 42"
      }
    ]
  }

Uso:

  legal-expand boe informe.md --overrides boe-overrides.json --output referencias-boe.md

Las referencias manuales aparecen con estado `manual` para distinguirlas de lo
detectado automaticamente.
