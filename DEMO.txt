CONTENIDO DE LA DEMO
--------------------------------------------------------------------------------

El notebook incluye 11 secciones:

 1. Instalacion
 2. Uso basico (expansion simple, multiple, variantes)
 3. Formatos de salida (plain, html, structured)
 4. Control global (configurar_globalmente, resetear, force_expansion)
 5. Opciones avanzadas (expand_only_first, exclude, include)

10. Extensibilidad (crear formatters personalizados)
11. Herramientas interactivas (buscador, expansor, analizador)


EJEMPLOS RAPIDOS
--------------------------------------------------------------------------------

# Expansion basica
from legal_expand import expandir_siglas
expandir_siglas('La AEAT gestiona el IVA')
# -> 'La AEAT (Agencia Estatal...) gestiona el IVA (Impuesto...)'

# Formato HTML (para web)
from legal_expand import ExpansionOptions
expandir_siglas('La AEAT', ExpansionOptions(format='html'))
# -> '<abbr title="Agencia...">AEAT</abbr> (Agencia...)'

# Solo primera ocurrencia (documentos largos)
expandir_siglas('AEAT... AEAT... AEAT', ExpansionOptions(expand_only_first=True))
# -> 'AEAT (Agencia...)... AEAT... AEAT'

# Buscar una sigla
from legal_expand import buscar_sigla
buscar_sigla('BOE')
# -> AcronymSearchResult(acronym='BOE', meanings=['Boletin Oficial...'])
